# jrrp 人品卡插画

- `a.png` ~ `f.png` 对应签到插件 `nonebot_plugin_sign` 的 a~f 六档运势（>80 / 61-80 / 41-60 / 21-40 / 1-20 / 0），其中 `b.png`（吉）已从新版六格图第二格重新裁切替换。
- `perfect.png` 用于人品值 >= 100（满值及突破 100）时的橙底插画，运势分档仍保持 `a`（大吉）。
- 原图自带圆角白边，裁切时先去掉外围白边再套圆角透明遮罩，放进人品卡后再由卡片自己的圆角遮罩收边。

替换插画时保持同样的去白边与圆角处理即可；卡片代码见
`src/plugins/nonebot_plugin_jrrp/card.py`。
